Status & kejujuran

Halaman ini adalah dokumentasi statis di Cloudflare Pages. API-nya sendiri adalah server Express — Pages tidak bisa menjalankan Express, jadi tidak ada endpoint publik live di sini. Untuk memakai API-nya, jalankan server sendiri (lokal atau VPS — lihat Panduan deploy). Tanpa GEMINI_API_KEY, server jalan mode demo: membalas dengan balasan contoh deterministik dan menandai "demo": true.

Catatan mentor Kalau ada yang klaim API ini live di Pages, itu bohong. Bukti jalan-nya ada di transkrip curl & tes otomatis repo.

Mulai cepat

  1. Clone & install

    git clone https://github.com/dezzorigin/synalum-ai-mentor.git
cd synalum-ai-mentor
npm install

  2. Isi API key (atau jalan demo)

    cp .env.example .env
# isi GEMINI_API_KEY di .env — tanpa key,
# server tetap jalan mode demo

  3. Jalankan & cek health

    npm run dev
curl -s http://localhost:3000/api/health

Referensi endpoint

Dua endpoint. Semua respons JSON. Semua error JSON — tidak ada halaman error HTML.

GET /api/health Cek server hidup, mode, dan model.

Respons 200 — contoh asli

{
  "status": "ok",
  "mode": "demo",
  "model": "gemini-2.5-flash",
  "version": "1.1.0",
  "uptime_seconds": 2
}

Field

FieldArti
statusSelalu "ok" bila server hidup.
mode"live" (pakai Gemini asli) atau "demo" (balasan contoh).
modelModel Gemini yang dipakai.
versionVersi API.
uptime_secondsLama server jalan (detik).
POST /api/chat Kirim riwayat chat, terima balasan mentor.

Request body

{
  "messages": [
    { "role": "user",
      "content": "Buatin roadmap belajar
        Web Development dari nol dong" }
  ]
}

Respons 200 — contoh asli (dipotong)

{
  "reply": "Oke bestie, real talk: roadmap
    Web Development dari nol…",
  "model": "gemini-2.5-flash",
  "demo": true
}

Aturan validasi

AturanDetail
messagesArray, 1–50 item. Kosong → 400.
role"user" atau "model". "assistant" diterima sebagai alias "model".
contentString tidak kosong, maks 4000 karakter.
BodyJSON, maks 100 KB. Bukan JSON → 400.
Rate limit30 permintaan / menit / IP. Lebih → 429 + header Retry-After.

Error

KodeArti
400Validasi gagal — pesan error menjelaskan field-nya.
405Method bukan POST ke /api/chat.
429Rate limit terlampaui.
500Gemini tidak bisa dihubungi.

Contoh pemakaian

Tiga cara memanggil endpoint yang sama. Pilih tab, salin, tempel, jalan.

Terminal 
curl -s -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Aku mager banget buat ngoding, motivasi dong"}]}'
Browser / frontend 
const res = await fetch("http://localhost:3000/api/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    messages: [{ role: "user", content: "Aku mager banget buat ngoding, motivasi dong" }],
  }),
});
const data = await res.json();
console.log(data.reply);
Node.js 20+ 
// Node 20+ punya fetch bawaan — tanpa dependensi.
const res = await fetch("http://localhost:3000/api/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    messages: [
      { role: "user", content: "Buatin roadmap belajar Web Development dari nol dong" },
      { role: "model", content: "Oke bestie, ini jalurnya…" },
      { role: "user", content: "Lanjut ke bagian proyeknya dong" },
    ],
  }),
});
console.log(await res.json());

Kirim seluruh riwayat tiap permintaan — API ini stateless, tidak menyimpan percakapan. UI chat di repo (public/) melakukan persis itu.

Deploy server

API ini butuh server Node.js — bukan hosting statis. Jalur yang didokumentasikan & teruji build-nya: Docker, lalu Coolify di VPS (atau platform apa pun yang menjalankan container).

  1. Build image

    docker build -t synalum-ai-mentor .
docker run -p 3000:3000 --env-file .env synalum-ai-mentor

  2. Atau pakai compose

    docker compose up -d --build
curl -s http://localhost:3000/api/health

  3. Coolify (VPS)

    Buat resource dari repo GitHub → isi GEMINI_API_KEY di Environment Variables → deploy. Healthcheck memakai GET /api/health. Langkah lengkap ada di docs/DEPLOY.md.

Batas & error

  • Stateless: riwayat chat tidak disimpan di server — kirim ulang tiap permintaan.
  • Rate limit in-memory: restart server menghapus hitungan. Untuk trafik ramai, pakai limiter berbasis Redis (lihat docs/DEPLOY.md).
  • Mode demo bukan Gemini: balasan contoh deterministik, cocok untuk tes & demo — jangan dipakai untuk menilai kualitas model.
  • API key: jangan pernah commit .env. Key bocor = cabut & buat baru di Google AI Studio.
